Where they all agree

Machines enforce the non-negotiables

Hooks, CI, presubmits and branch protection are what actually enforce. Prose rules are for judgment.5,11,26

Precision over recall

A noisy reviewer gets ignored. Filter hard before a human sees anything.1,10,27

Evidence, not claims

Show the test output, cite file:line, make every finding actionable.3,11,28

Small and reversible

Small changes, feature flags, fast rollback.1,12,25

Fix repeats at the source

A recurring review comment becomes a lint rule, an analyzer or an instruction-file line.1,12,27

Measure the reviewer

Evals on known bugs, noise labels, acceptance rates. The reviewer is tested like code.1,10,31
